# AI-Agent Security and Trustworthy AI Project Portfolio

This repository contains research-oriented work focused on trustworthy AI, AI-agent security, secure autonomous systems, and applied machine learning.

## Research Interests
- Trustworthy AI
- AI safety and robustness
- Secure autonomous systems
- Policy-aware AI agents
- Hybrid AI and formal methods
- Applied AI in healthcare, cybersecurity, and intelligent decision support

## Included Work

### 1. Mechanisms for Enforcing Authorisation and Usage-Control Policies in LLM Agents
A doctoral-track research proposal examining how AI-derived semantic context can be integrated with formal runtime enforcement for LLM-based agents. The work explores authorisation, usage-control policies, obligations, revocation, and effect-binding in multi-agent workflows.

### 2. Applied AI, Machine Learning, and Deep Learning Project Report
A project report describing applied AI, machine learning, and deep learning work in real-world intelligent systems, data-driven decision support, and NLP-enabled intelligent applications.

### 3. AI-Agent Security Study
An independent study focused on security challenges in tool-using LLM agents and autonomous AI systems, including policy enforcement, bounded autonomy, and responsible use.
